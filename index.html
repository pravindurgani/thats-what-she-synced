Install in four steps.

No download. You build it from source.

You need an Apple silicon Mac on macOS 14.4 or later, plus Apple’s Command Line Tools:

xcode-select --install
  1. 1

    Build it:

    git clone https://github.com/pravindurgani/thats-what-she-synced.git
cd thats-what-she-synced
VORSSAINT_DEV_OPTIMIZE=1 ./build.sh --dev --install
  2. 2

    Let it hear the beat: System Settings → Privacy & Security → Screen & System Audio Recording → under System Audio Recording Only, turn on Vorssaint (Developer).

  3. 3

    Switch on, in the app’s Settings: Dynamic Island, Bars follow the music and Accessory alerts. For the cast and the agents, also install Companion and AI Agents on the Features page.

  4. 4

    Play a song and hover over the notch.

Two islands?
Also running the official Vorssaint? Quit it, so you don’t get two islands.
Not working?
No beat or Firefox trouble: the README’s fixes cover both.
Update
git pull && VORSSAINT_DEV_OPTIMIZE=1 ./build.sh --dev --install
